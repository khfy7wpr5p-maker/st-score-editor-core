## No-data-loss gate

For the reviewed Guitar/TAB technical families exercised here — string/fret, staff tuning, bend, hammer-on, pull-off, harmonic, pluck and golpe — success requires one of two explicit outcomes:

1. source evidence is preserved in the raw sidecar and deterministically joined to the canonical note identity; or
2. import fails closed with a diagnostic.

Silent deletion is not an admitted outcome. The SES-90 automated corpus test checks the complete expected preserved-symbol inventory for the Guitar/TAB fixture and independently reruns the raw preservation extractor.

## Canonical authority

- Native TypeScript import remains the fast path.
- Partitura is invoked only for an eligible classified file-open/import failure.
- Partitura output must pass the ST canonical mapper before admission.
- `ScoreDocumentV3 + NotationDocumentV4` remain canonical.
- `EditorSessionV4 / EditorHistoryV4` remain mutation/history authority.
- Raw-preserved symbols remain noncanonical evidence.
- Partitura is not invoked during selection, editing, Undo, Redo, or rendering.
