# P06 Audio v0.1.0 Integration Notes

This branch intentionally treats the ST Score Audio Engine GitHub Release `v0.1.0` as the first admissible external distribution identity.

The implementation must consume the upstream public contract rather than duplicating its request types. Any temporary local shape that mirrors the upstream contract is not acceptable as the final state.

The integration remains noncanonical, revision-bound, default-off, and capability-local. No renderer geometry may become pitch authority. No merge, release, deployment, or SesliTab cutover is authorized here.
